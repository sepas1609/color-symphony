# 🎨🎵 Color Symphony — Polyphonic Generative Audio Studio

Color Symphony translates freehand cursor and touch motion across the viewport into dynamic polyphonic harmonic soundscapes.

## 🎼 Harmonic Architecture
- **Web Audio API Engine**: Custom polyphonic oscillator bank featuring sine, triangle, and frequency modulation synthesis.
- **Pentatonic Pitch Quantization**: Y-axis coordinates are quantised into equal-tempered musical scales, guaranteeing harmonious chords.
- **Spatial Panning**: X-axis coordinates map directly to StereoPannerNode channels for binaural immersion.
- **Zero Dependencies**: Pure HTML5 Canvas 2D + native Web Audio API.
